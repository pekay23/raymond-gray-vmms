## Scope and completion

The full goal covers the complete specification and platform rollout. The next milestone is the one-site workshop operations pilot; see [the detailed build plan](operational-workshop-pilot-agent-plan.md). A functioning foundation or a passing build does not complete the full goal. The owner has authorized production deployment after local implementation and tests; deploy only the reviewed change after the applicable identity, safety, data, restore, rollback and pilot acceptance gates pass. Historical migration and physical-device checks remain separate work.

Documentation and local implementation are reversible. Production infrastructure purchases, DNS changes, deployment, real staff-data import, and platform publishing require a concrete configuration and the user's authorization at that point.
